# ColorNamer

A Chrome extension that names any color on your screen. Click the icon, click a pixel, get the color's name.

![ColorNamer demo](demo.gif)

## Install (2 minutes, no build needed)

1. **Download this folder** — click the green **Code** button above → **Download ZIP**, then unzip it. (Or `git clone` it.)
2. Open Chrome and go to **`chrome://extensions`**
3. Turn on **Developer mode** (toggle, top-right)
4. Click **Load unpacked** and choose the **ColorNamer** folder
5. Done. Pin the icon if you like.

## Use

1. Click the **ColorNamer** icon in your toolbar.
2. Your cursor becomes an eyedropper — **click any pixel** on the page.
3. A little card shows the **color's name**, its hex (click to copy), and similar colors.

Press **Esc** or **✕** to close the card.

> Note: Chrome blocks extensions on special pages (`chrome://`, the Web Store, the new-tab page, PDFs). Use it on any normal website.
